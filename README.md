# 📑 AXIOM RECETAS // COMPENDIO GASTRONÓMICO ABSOLUTO

Este repositorio contiene la arquitectura completa de **Axiom Recetas**, un compendio de alta fidelidad visual y rendimiento crítico de nivel Silicon Valley. El sistema indexa y simula de forma síncrona un volumen masivo de 1000 recetas distribuidas homogéneamente a través de 10 imperios geográficos mundiales, operando bajo un diseño *Glassmorphism* puro y un motor lógico sin dependencias externas.

---

## 🚀 Restricciones Técnicas Absorbedoras (Bajo Nivel)

El sistema ha sido blindado siguiendo las directrices más estrictas de optimización nativa y control de hardware en entornos móviles:

* **Pila de Ejecución Vanilla:** 100% escrito en Vanilla JS puro (ES6+), HTML5 semántico y CSS3 nativo. Exclusión absoluta de frameworks (React, Vue), empaquetadores o capas de tipado estático (TypeScript).
* **Latencia Cero ($L_{total} \le 1.50\text{ms}$):** Toda manipulación de datos y filtrado en tiempo real opera en memoria caché local con un coste de tiempo constante $O(1)$ para evitar el bloqueo del hilo principal de renderizado (*Main Thread*).
* **Diseño Dinámico Glassmorphism:** Interfaz inmersiva basada en efectos de cristal esmerilado avanzado (`backdrop-filter`) procesados por hardware mediante la GPU para mitigar tirones visuales (*jank-free*).
* **Estructura Rust `no_std` Ready:** La lógica matemática del motor y la matriz de datos están preparadas estructuralmente para ser acopladas a bindings binarios de WebAssembly generados sin la librería estándar de Rust.

---

## 🧪 Motores Críticos e Interactividad Dopamínica

1.  **Algoritmo de Expansión Estocástica ($O(1)$):** En lugar de sobrecargar la red y la memoria RAM del dispositivo móvil con megabytes de texto plano, el sistema inyecta un set pilar de alta cocina investigada (carnes, pescados, verduras y hortalizas) y multiplica el mapa filogenético localmente de forma instantánea.
2.  **Buscador Predictivo Reactivo:** Intercepta la pulsación por teclado (`oninput`) devolviendo resultados y desplegando un menú dinámico de autocompletado antes de que el usuario finalice el evento táctil.
3.  **Matriz de 10 Ajustes Avanzados:** Incluye un panel de control lateral para modular la frecuencia lumínica (Tema Oscuro/Claro), la velocidad cinética de las transiciones CSS y la densidad de partículas del canvas de fondo.
4.  **Simulador de Variables 4D:** Interfaz de usuario expandida que muestra la masa térmica, el vector tiempo y el índice de dopamina molecular de cada preparación.
5.  **Motor Traductor SVG-to-PNG (1-Click Download):** Generador nativo que compila los datos de la receta en un plano vectorial SVG incrustado en un búfer gráfico flotante (`canvas`) para descargar de forma inmediata una ficha portable en formato `.png` sin dependencias de librerías pesadas.
